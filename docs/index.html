Features

Small utility, careful details.

Everything runs locally on your Mac, with no accounts, servers or network access.

Global pin hotkey

Pin or unpin the frontmost window from any app with Control-Option-P. You can re-record the shortcut in Settings or reset it to the default.

Multiple pinned windows

Pin as many windows as you need. Their order stays stable, and windows with identical titles are told apart by window ID.

Optional border marker

Draw a click-through colored border around pinned windows. Choose the color, thickness from 1 to 10 pt, and opacity.

Gentle and full-screen modes

Gentle mode raises pinned windows only when the active app changes. Pins also pause while a non-pinned app is full screen.

Menu bar control

The pin icon fills when something is pinned. The menu lists each pinned window by app and title, with Focus, Unpin and Unpin All actions.

Automatic cleanup

Pins are dropped when a window closes or its app quits. Minimized windows and windows on other Spaces pause, then resume when visible. Launch at login is optional.

Install

Up and running in a minute.

PinWindowOnTop is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download PinWindowOnTop-macOS.zip and unzip it.
  2. Move PinWindowOnTop.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/PinWindowOnTop.app
  4. When prompted, grant Accessibility access in System Settings Privacy Security Accessibility so the app can find and raise windows.

FAQ

Questions, answered.

Is PinWindowOnTop really free and open source?

Yes. It is released under the MIT license, and the full source is on GitHub. There are no accounts, subscriptions or paid tiers, and optional donations help support development.

What permissions does it need?

It needs Accessibility access to find the focused window, raise pinned windows, and watch for move, resize, minimize and close events. It does not request Screen Recording, Microphone, Camera or network access, and it reads only window titles, positions and sizes.

Where is my data stored?

Only on your Mac. Your hotkey and border appearance settings are saved in the app's local preferences. Pinned windows are tracked in memory and are not persisted or sent anywhere.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to launch it, or build it yourself from source with Xcode and XcodeGen.
